# HU Sport Court

比赛结束，聊个明白。

HU 是一个赛后观点互动网站的第一版前端原型。白色页面、淡出的体育场顶部、独立赛事色彩分区、简洁比分入口、红蓝辩论席和独立的中立讨论。

## 这一版可以做什么

- 点击比分查看进球、比赛数据和示例首发。
- 点击进入法庭，经过天秤摇摆和上下幕布动画进入辩论席。
- 选择正方、反方或不站队，再查看评论、发言、点赞和展开回复。
- 陪审席投票和修改选择。每场一票，修改时不增加总票数。
- 查看已结案的社区投票结果。
- 预约未开赛的示例比赛，在我的关注中查看。
- 电脑宽屏与手机竖屏布局。

## 当前范围

比赛、阵容、时间、进球和初始投票均为示例数据，并非真实2026赛程。正在进行的示例比赛不会自动完赛。14场示例覆盖欧冠、英超、西甲、德甲、意甲。开庭中的案例可一直参与：每次进入重新开始12小时演示倒计时，到期循环；切换法庭内标签不会重置。已结案案例固定展示结果，不受演示时间影响。

发言、点赞、关注和投票只保存在当前页面会话，刷新后重置。没有账号服务器、实时比分、跨用户同步或通知服务。社区投票结果不是事实认定或 AI 判决。

## 运行

Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
npm run build
npm run test:sites
```

React + Vite；图标来自 Phosphor。入口 `src/App.jsx`，设计样式 `src/styles.css`，示例数据及可循环的演示倒计时在 `src/data.js`。

后续接入持久数据库、身份验证和授权比分 API 时，替换数据模块并把投票、发言、结案时间改为服务器维护。

## 部署

GitHub Pages 工作流构建 `dist/client`。仓库 Settings → Pages 的 Source 设置为 GitHub Actions。网站使用 `/hu-sport-court/` 路径及 hash 路由。

模板同时保留 Sites Worker 和构建元数据；没有把现有旧站点的项目 ID 写进此新项目。

## 视觉素材

体育场背景为本项目生成的图像。球队徽章通过 football-data.org 与 ESPN 的公开 crest 地址显示；商标属于各球队，生产使用前需确认素材授权。Noto Sans SC 来自 Google Fonts，Phosphor Icons 为 MIT 图标库。项目没有复制参考仓库的源码。
